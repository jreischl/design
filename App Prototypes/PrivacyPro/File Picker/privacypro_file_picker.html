    Accessibility notes
    • Native: the drop zone is a <label> wrapping a real <input type="file">, so it's Tab-focusable, Enter/Space opens the picker, and screen readers announce it as a file input.
    • Focus ring: visible 3px teal ring on keyboard focus (not on click).
    • Live region: upload progress and errors are announced via aria-live="polite".
    • Remove buttons: each has an aria-label naming the file being removed.
    • Drop zone help text is linked via aria-describedby so SRs hear the constraints alongside the control.
